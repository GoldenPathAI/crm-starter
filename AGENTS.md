Read `CLAUDE.md` in this directory. It is the full contract for working in this repo:
architecture, the data layer, per-workspace číselníky, the shared datagrid, the audit and
undo model, the API and CLI surface, and the coding conventions.

Task-specific guides live in `.claude/skills/`:

- `crm-module` for adding a new entity end to end
- `crm-datagrid` for any list, table or grid surface
- `crm-design` for any UI or styling work
- `verify` for proving a change works in the running app
